# Dataset

## Source

This project uses the `adae.csv` clinical adverse event dataset from the Pharmaverse ADaM ecosystem.

## Setup Instructions

1. Obtain the `adae.csv` dataset from pharmaverseadam::adae.
2. Place the CSV file inside this directory.
3. Ensure the filename is exactly `adae.csv`.

## Expected Location

```text
data/
└── adae.csv
```

The dataset is excluded from the GitHub repository. Users must provide their own permitted copy before running the test script.
